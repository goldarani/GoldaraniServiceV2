سرویس‌یار گلدرانی — نسخه ۱.۱

ویژگی‌ها:
- دریافت نام کاربر در اولین اجرا و نمایش «سلام [نام]، خوش اومدی» در صفحه خانه
- آیکون اختصاصی برنامه به‌جای آیکون پیش‌فرض اندروید
- تنظیمات حالت روشن/تاریک و اندازه نوشته‌ها
- حذف کامل بخش فاکتورها از رابط کاربری
- ثبت سرویس، فهرست ساختمان‌ها، ثبت خرابی‌ها و مدیریت طلب‌ها
- ذخیره اطلاعات روی خود گوشی با SQLite

ساخت APK از طریق GitHub Actions:
1. محتویات این پوشه را در مخزن GoldaraniService قرار بده و فایل‌های هم‌نام را جایگزین کن.
2. از تب Actions، گردش کار Build Goldarani APK را اجرا کن.
3. پس از موفقیت، از بخش Artifacts فایل GoldaraniService-debug-apk را دانلود و از حالت فشرده خارج کن.
4. فایل app-debug.apk را روی گوشی اندرویدی نصب کن.

توجه: این بسته سورس پروژه است، نه فایل APK آماده. APK باید بعد از به‌روزرسانی مخزن دوباره ساخته شود.
